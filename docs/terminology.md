# 用語の使い分け

認証、セッション引き渡し、参加アプリへの利用開始、画面の制御を、次の用語で区別します。

| 用語 | 意味 |
| --- | --- |
| ログイン | 認証サーバーで本人を確認し、認証済み状態を得ること |
| 引き渡し | 認証サーバーが認証済みセッションを参加アプリへ渡すこと |
| 入場 | 参加アプリが引き渡されたセッションを受け取り、その参加アプリの利用を開始すること |
| ログアウト | 現在の参加アプリまたは認証サーバーのセッションを終了すること |
| アクセス制御 | ロール、利用権限、URLなどに基づいて、画面や操作の可否を決めること |

`入場` は認証サーバーの本人確認とは区別します。ログインは認証サーバーで行い、入場は参加アプリでセッションを受け取って利用を始める処理です。未ログインの場合は、通常、認証サーバーへ引き渡しを経てログインし、その後に参加アプリへ入場します。

`アクセス制御` は入場可否だけでなく、入場後に利用できる画面や操作にも適用します。入場判定とロールや利用権限による画面分岐は、別の処理として扱います。
